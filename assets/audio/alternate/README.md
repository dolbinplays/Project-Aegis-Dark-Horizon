# Dark Horizon Alternate Soundtrack

These 15 original cues were generated for Project Aegis in ElevenLabs and provide a one-to-one alternative for every existing soundtrack context.

- Start: `dark_horizon_overture.mp3`
- Command menu: `command_directive.mp3`
- Geoscape: `global_vigil.mp3`
- Base: `fort_aegis.mp3`
- Inventory: `quartermaster_ledger.mp3`
- Database: `mainframe_archive.mp3`
- Soldiers: `barracks_after_midnight.mp3`
- Research: `unknown_specimen.mp3`
- Workshop: `assembly_line_zero.mp3`
- Squads: `fireteam_covenant.mp3`
- Sickbay: `recovery_ward.mp3`
- Missions: `contact_in_the_dark.mp3`
- Reports: `after_action.mp3`
- Memorial: `names_on_the_wall.mp3`
- Pause: `command_suspended.mp3`

The in-game `Original Soundtrack` / `Dark Horizon Alternate` setting chooses the active bank. If an alternate cue cannot load, playback falls back to the corresponding original track and then the synthesized theme.

Generated tactical sound-effect candidates remain in the signed-in ElevenLabs project for auditioning and later normalized file replacement. The browser's Enhanced Tactical SFX profile already owns category routing for role footsteps, weapons, impacts, injury, and death while preserving Original SFX as a player choice.
